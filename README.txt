# Happy Monthsary, My Love! 💗

A mobile-friendly romantic website made with HTML, CSS, and JavaScript.

## Files
- `index.html` — website content
- `style.css` — pink romantic styling and responsive mobile layout
- `script.js` — countdown and interactive buttons
- `photos/` — add your couple photos here
- `music/` — add your song here

## Personalize it
1. Open `script.js` in a text editor.
2. Change `relationshipStart` to your actual relationship start date in `YYYY-MM-DD` format.
   Example: `new Date("2024-02-14T00:00:00")`
3. In `index.html`, edit the letter, reasons, and photo captions to make them personal.
4. Add your photos in the `photos` folder and name them exactly:
   - `photo1.jpg`
   - `photo2.jpg`
   - `photo3.jpg`
   - `photo4.jpg`
   If your photos are PNG, either convert them to JPG or update the filenames in `index.html`.
5. Add a song file you have permission to use at `music/our-song.mp3`. Keep the filename exact. Phones usually require a tap to start playback.
6. Open `index.html` in a browser to preview it.

## Publish for free with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com.
2. Create a new public repository, for example `our-monthsary`.
3. Upload the contents of this folder (upload `index.html`, `style.css`, `script.js`, and the `photos` and `music` folders). Do not upload only the ZIP file.
4. In the repository, open **Settings → Pages**.
5. Under the build/deployment source, choose **Deploy from a branch**; select `main` and `/ (root)`, then save.
6. Wait a few minutes. The Pages section will show the website URL, usually `https://YOUR-USERNAME.github.io/our-monthsary/`.
7. Open that URL on your phone to test it, then send it to your partner.

Note: GitHub Pages sites are public to anyone with the link. Do not include private information or photos you do not want publicly accessible. A song file can increase the upload size; use a reasonably sized MP3.
